# House Brain Energy AI

Persistent local energy analytics, learned forecasts and bounded shadow planning.
Runs without a chatbot, LLM API or third-party Python distributions. Native
controllers retain equipment authority. Startup refuses control modes.

This unreleased experimental app has not been installed or qualified on Home
Assistant/ARM64. Source tests and synthetic replay do not establish household
savings, appliance identity or physical acceptance.

The app directory is a generic package. Household bindings, accepted rulings,
private evidence and adapter configuration are supplied separately through a
reviewed digest-bound private bundle. No household fallback exists. Missing or
invalid setup fails before database creation or Home Assistant access.

See [DOCS.md](DOCS.md) for interfaces, resource bounds, qualification and recovery.
