Today the Pi's own rule agent answers, and a playbook from a solved real case ranks first when one matches; internet research and the MacBook agent come in later steps. Investigations never act: any fix is your tap in Maintenance or the Deployer.</p></section>
<section><h2>Playbooks</h2><p class="line" id="playbooks"></p><p class="muted">Solved real cases, written down so the house recognises them again without a model or a subscription. Each one says what to check, what to ask you, how the fix is verified and when not to use it. A match is a suggestion only: Systems AI never acts.</p></section>
<section><h2>World changes</h2><p class="line" id="world"></p><p class="muted">Public security news, only where it touches what runs here: the CISA list of vulnerabilities attackers are using now, and GitHub security advisories for Home Assistant Core, OS, the Supervisor and ESPHome. Read at 03:20 and 15:20, 10 requests a day at most, no key, $0, none while held. A source that could not be read says so; it never reads as "no threats". Any update stays your tap in Maintenance.</p></section>
